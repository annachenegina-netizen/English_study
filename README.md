# English Trainer

Личный тренажёр английского: слова, грамматика и чат. Уровни открываются по мере прохождения.

## Как устроено

- **Слова** — частые слова живой речи. Видишь слово, составляешь с ним своё предложение, ИИ проверяет. Выученные слова возвращаются на повторение через 1, 3, 7, 14 и 30 дней.
- **Грамматика** — короткое правило, потом собираешь предложения из слов и переводишь с русского.
- **Чат** — ИИ задаёт вопросы и пользуется только той грамматикой и словами, которые ты уже прошёл.
- **Уровни** — их 6. Уровень закрыт, когда выучено 80% его слов и пройдены обе темы грамматики.

## Запуск на Vercel

1. Импортируй этот репозиторий в Vercel. Framework Preset — **Other**, остальное не трогай.
2. В проекте открой **Settings → Environment Variables** и добавь:
   - `GEMINI_API_KEY` — ключ с https://aistudio.google.com/apikey
   - `APP_PASSWORD` — любой пароль, им ты будешь входить в тренажёр
3. Открой вкладку **Storage → Create Database → Upstash (Redis)**, бесплатный тариф, и подключи базу к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
4. Сделай **Redeploy**, чтобы переменные подхватились.

Без шага 3 всё работает, но прогресс хранится только в браузере.

## Где что лежит

| Что | Где |
|---|---|
| Слова по уровням | `js/data/words.js` |
| Темы грамматики и задания | `js/data/grammar.js` |
| Как ИИ объясняет ошибки | `api/_lib/gemini.js`, блок `TEACHER_STYLE` |
| Поведение ИИ в чате | `api/chat.js` |
| Дневная норма новых слов | `js/store.js`, `NEW_WORDS_PER_DAY` |
| Модель Gemini | переменная `GEMINI_MODEL` или `DEFAULT_MODEL` в `api/_lib/gemini.js` |
